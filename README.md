# Lê Văn Cảm — Personal Portfolio

A stunning personal portfolio website built with **React + Vite** featuring:

- 🎯 **Antigravity Physics** — Matter.js powered skill bubbles that float, collide, and respond to mouse interaction
- ⭐ **Animated Star Canvas** — Twinkling particles in the hero section
- ✍️ **Typing Animation** — Cycling role titles
- 🃏 **3D Hover Effects** — Project cards with perspective transforms
- 📱 **Fully Responsive** — Mobile-first design
- 🎨 **Deep Space Theme** — Dark UI with glowing accents

## Tech Stack

- **React 18** + **Vite 5**
- **Matter.js** — 2D physics engine for antigravity skill bubbles
- **CSS Custom Properties** — Design system tokens
- **Space Grotesk** + **Fira Code** — Typography

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Production build
npm run build
```

## Deploy

### Cloudflare Pages (Recommended)

1. Push to GitHub
2. Go to [Cloudflare Pages](https://pages.cloudflare.com)
3. Connect GitHub repo → Select `personal-portfolio`
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy** 🚀

### Vercel

```bash
npx vercel --prod
```

### Netlify

```bash
npx netlify deploy --dir=dist --prod
```
